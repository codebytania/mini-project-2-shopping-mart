# 🛒 Shopping Mart

A modern and responsive **Shopping Mart** web application built using HTML, CSS, and JavaScript.

## 📌 About the Project

Shopping Mart is an interactive online shopping platform where users can browse products, search for products, filter products by category, add products to a shopping cart, manage quantities, save products to a wishlist, and switch between dark and light mode.

## ✨ Features

* 🛒 Add products to cart
* ➕ Increase product quantity
* ➖ Decrease product quantity
* 🗑️ Remove products from cart
* 🔎 Live product search
* 🏷️ Category filtering
* ❤️ Wishlist
* 🌙 Dark/Light mode
* 🔔 Toast notifications
* 💾 LocalStorage support
* 📦 Dynamically generated products
* 📱 Responsive design
* ✨ Modern user interface

## 🏷️ Product Categories

* Electronics
* Fashion
* Beauty
* Home

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Browse the available products.
5. Add products to the cart.
6. Search or filter products.
7. Add favorite products to the wishlist.
8. Try the Dark/Light mode.

## 💾 LocalStorage

The project uses browser LocalStorage to save:

* Cart items
* Wishlist items
* Theme preference

This means the user's preferences remain saved even after refreshing the page.
